# ゆいんくらふと

空に浮かぶパステルカラーの島で、ブロックを掘ったり置いたりして遊ぶWebゲームです。
iPadのSafariで遊ぶことを主な目的にしています。依存ライブラリとビルド作業はありません。

## 動かす

```bash
python3 -m http.server 8766 --bind 127.0.0.1
```

ブラウザで http://localhost:8766 を開きます。
同じWi-FiのiPadから試すときは `--bind 127.0.0.1` を外し、`http://（MacのIPアドレス）:8766` を開きます。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面とボタン |
| `game.js` | ゲーム本体（地形、描画、操作、保存） |
| `sw.js` | オフライン用キャッシュ（https または localhost で有効） |
| `manifest.webmanifest` / `icon.png` | ホーム画面に追加するときの設定 |
